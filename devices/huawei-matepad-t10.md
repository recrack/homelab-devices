# Huawei MatePad T 10 주문용 단말

SFF 게시물에서 식당 주문용으로 수거한 태블릿의 기기 정보 화면에 `HUAWEI MatePad T`, 모델 `AGRK-W09`, Kirin 710A, RAM 2GB, EMUI 10.1.0 및 Android 10이 표시됩니다. 화웨이 지원 페이지에서는 `AGRK-W09`를 MatePad T 10의 Wi-Fi 모델로 안내합니다. 원글에 주문 서비스 이름은 나오지 않습니다. [SFF 단말 사진](https://m.dcinside.com/board/sff/1798556) · [화웨이 모델 안내](https://consumer.huawei.com/jp/support/tablets/matepad-t-10/)

## 공개 사양

화면과 연결 사양은 화웨이 제품 문서 기준입니다. RAM 2GB와 EMUI 버전은 SFF 사진에도 나오며, 해당 주문 단말의 저장공간은 사진에 표시되지 않습니다. [화웨이 공식 사양](https://consumer.huawei.com/sa-en/tablets/matepad-t-10/specs/)

| 항목 | 사양 |
|---|---|
| SoC | Kirin 710A, Cortex-A73 4코어 + Cortex-A53 4코어 |
| 화면 | 9.7인치 IPS 터치, 1280×800 |
| RAM | SFF 사진 기준 2GB |
| 운영체제 | EMUI 10.1, Android 10 기반 |
| 연결 | Wi-Fi 2.4/5GHz, Bluetooth 4.2, USB-C 2.0, microSD |
| 오디오 | 스피커 2개, 마이크 1개가 공식 사양에 기재됨 |

## 홈랩 활용 상태

**조사 후보.** SFF 댓글에서 벽에 거는 스마트홈 화면으로 쓰자는 제안이 나왔습니다. 해당 주문 단말에서 브라우저·일반 앱을 실행하거나 Home Assistant를 표시한 결과는 확인되지 않았습니다. 본인 기기에서 브라우저를 평소처럼 열 수 있다면 대시보드가 표시되는지 확인할 수 있습니다. [SFF 글과 댓글](https://m.dcinside.com/board/sff/1798556)
